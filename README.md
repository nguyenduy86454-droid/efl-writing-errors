# Vietnamese EFL Writing Errors: Human vs AI Annotation

A small pilot study on common English writing errors of
English-major students at Dong Thap University, and how
accurately AI tools can detect them.

## Research question
Which error types are most common in students' English
writing, and how accurately do AI tools detect them
compared with manual annotation?

## Method
1. Collect anonymized essays with written consent
2. Annotate errors manually (see annotation_scheme.md)
3. Run AI-based checking on the same texts
4. Compare AI detection with manual labels

## Error codes
ART (article), TNS (tense), SVA (subject-verb agreement),
PREP (preposition), WC (word choice), SP (spelling),
WO (word order)
